# AI Test Officer User Guide Assets

This folder keeps the end-user usage guide separate from architecture notes and engineering plans.

- `AI-Test-Officer-使用说明.docx`: Word usage guide for reviewers and new users.
- `assets/`: screenshots captured from the running Workbench UI.
- `rendered/`: internal render QA output for the Word document.

The source code, run reports, scenario registry, and CI scripts remain in their original project folders.
